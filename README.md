# Hostess — One City. One Hostess.

Кинематографический лендинг на английском о бронировании, предзаказах и общей программе лояльности между заведениями. Одна закреплённая карта Манхэттена сопровождает восемь глав: знакомство с городом, поиск места, стол, предзаказ, бонусная сеть, инструменты для заведений, единый путь гостя и финальный призыв.

## Локальный запуск

Нужны Node.js 20.9 или новее и npm.

```sh
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000). Сервер разработки привязан к локальному компьютеру.

В комплекте подготовлен `.env.local` с предоставленным публичным токеном Mapbox. Этот файл исключён из Git. Для нового окружения скопируйте `.env.example` в `.env.local` и задайте свой токен с префиксом `pk.`:

```env
NEXT_PUBLIC_MAPBOX_TOKEN=pk.YOUR_PUBLIC_MAPBOX_TOKEN
```

Токен Mapbox с префиксом `pk.` доступен браузеру по назначению. Для публикации ограничьте его разрешёнными адресами сайта в настройках Mapbox. Ранее переданный секретный токен `sk.` в проекте не используется: его необходимо отозвать и заменить в аккаунте Mapbox.

## Сборка и публикация

```sh
npm run lint
npm run typecheck
npm run build
```

Next.js настроен на статический экспорт. После успешной сборки готовый сайт находится в папке `out/`; её можно разместить на статическом хостинге. Публичный токен подставляется при сборке: после его изменения соберите сайт заново.

Для Vercel импортируйте проект, выберите Next.js, добавьте переменную `NEXT_PUBLIC_MAPBOX_TOKEN` и используйте команду сборки `npm run build`. Сайт не требует отдельного сервера приложения или базы данных.

## Что можно попробовать

- Прокрутить весь рассказ или переходить между главами через навигацию.
- Выбирать заведения в коллекции и на карте.
- Изменять параметры примерного бронирования, знакомиться с предзаказом и бонусной сетью.
- Открывать финальные сценарии для гостя и заведения.

Названия заведений, расположение точек, даты, места, меню, заказы, бонусы и показатели — иллюстративные данные. Все действия происходят в браузере. Сайт не отправляет заявки, не принимает оплату и не создаёт реальные бронирования; серверные интеграции в этот проект не входят.

## Карта, движение и доступность

Карта использует Mapbox GL JS и нуждается в WebGL, доступе к сети и действительном публичном токене. Камера непрерывно меняет положение, масштаб и угол по мере прокрутки; полигональные акценты, точки и маршруты раскрывают смысл текущей главы. Управление прокруткой остаётся у страницы.

Для небольших экранов предусмотрены адаптивная композиция и облегчённая карта. Настройка системы «уменьшить движение» учитывается в анимациях. Если WebGL, карта или сетевые ресурсы недоступны, интерфейс сохраняет основное содержимое и показывает резервную визуализацию.

Переключатель `MOTION ON / CALM MOTION` позволяет выбрать спокойный режим вручную. Для проверки иллюстрированной резервной сцены откройте `/?city=illustrated`; обычный адрес использует настоящую карту. Атрибуция Mapbox и OpenStreetMap сохранена.

Предпросмотр и production используют отдельные папки `.next-dev/` и `.next/`. Это позволяет собирать экспорт, не прерывая локальный просмотр.
