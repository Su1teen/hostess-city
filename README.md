# Hostess — лендинг

Сторителлинг-сайт Hostess на русском: ночная 3D-карта Манхэттена (Mapbox Standard, пресет `night`) и один вечер гостя, который проходит по реальному пешеходному маршруту. Справа — настоящие экраны приложения [hostes.online](https://hostes.online). Вторая часть сайта — для заведений: Hostess Command Center, схема зала, AI-хостес в WhatsApp, аналитика и интеграции.

## Как устроена история

- `lib/story.ts` — главы, заведения, ключевые кадры камеры. Камера едет за «головой» маршрута и смотрит по направлению движения, поэтому золотая линия всегда остаётся в центральной полосе: между текстом и телефоном.
- `lib/route.ts` — маршрут Юнион-сквер → Selfie → XOXO → Tangiers (2,7 км), получен из Mapbox Directions API (walking).
- `components/CityMap.tsx` — карта, линия маршрута, сеть заведений в бизнес-главах, метки.
- `components/Devices.tsx` — телефон со сменой экранов, ноутбук, планшет со схемой зала, переписка с AI-хостес.
- `public/screens/` — скриншоты из hostes.online (мобильные) и Command Center (десктоп).

Заведения и экраны — из рабочей версии Hostess (Астана). Нью-Йорк — сцена для истории.

## Локальный запуск

Нужен Node.js 20.9+.

```sh
npm install
npm run dev
```

Скопируйте `.env.example` в `.env.local` и укажите публичный токен Mapbox (`pk.…`). Открыть http://127.0.0.1:3000.

## Сборка и деплой (Railway)

```sh
npm run build   # статический экспорт в out/
npm start       # отдаёт out/ на $PORT
```

На Railway: подключите репозиторий и добавьте переменную `NEXT_PUBLIC_MAPBOX_TOKEN` (публичный `pk.`-токен). Если её не было при сборке, `npm start` всё равно передаст токен браузеру через `runtime-config.json` — достаточно перезапуска. Build — `npm run build`, start — `npm start`. Ограничьте токен адресами сайта в настройках Mapbox (URL restrictions). Без токена сайт работает, но вместо карты показывается фон.
